# Third-party licences

Porthouse's own code is under the [0BSD licence](LICENSE). The programs that you install also contain or work with the following, each under its own licence. The full texts are in the [licenses](licenses) folder, which every package and the Windows installer install next to the program.

| Component | Where | Licence | Text |
|---|---|---|---|
| Rust crates linked into `porthouse-server`, `porthouse-clientd`, and `porthouse-client` | all packages | MIT, Apache-2.0, ISC, BSD, Unlicense, and similar permissive licences | [licenses/rust-crates.txt](licenses/rust-crates.txt) |
| Qt 6 libraries used by the Porthouse program | Windows installer (Qt files are shipped unmodified next to the program) | LGPL-3.0 | [licenses/LGPL-3.0.txt](licenses/LGPL-3.0.txt), [licenses/GPL-3.0.txt](licenses/GPL-3.0.txt) |
| usbip-win2 driver installer | Windows installer, installed only when you choose to use devices from other computers | BSD-2-Clause | [licenses/usbip-win2.txt](licenses/usbip-win2.txt) |
| Microsoft Visual C++ runtime | Windows installer, next to the program | Microsoft redistributable terms for Visual Studio | |

The Linux packages use the Qt that comes with your system, so they ship no Qt files of their own.

## Qt

The Porthouse program uses Qt 6, copyright The Qt Company Ltd. and other contributors, under the GNU Lesser General Public Licence version 3. The Windows installer includes the Qt libraries as separate DLL files, so you can replace them with your own build of the same Qt version. The Qt source code is available from <https://download.qt.io/official_releases/qt/> and <https://code.qt.io/>. Porthouse's own source is at <https://github.com/RisPNG/porthouse>.

## Keeping the Rust list current

`licenses/rust-crates.txt` is generated by `scripts/third-party-licenses.py`, and CI fails when it is out of date.
